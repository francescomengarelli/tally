# tally Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust CLI that runs Claude Code as any of several subscription accounts sharing one setup, and reports usage left across all of them in one unit.

**Architecture:** Pure layers (config, maths, pick, formatting) are unit-tested with fixed inputs. I/O layers (credentials, HTTP, cache, links, config editing) sit behind small functions; the network sits behind a `Net` trait so nothing in tests touches it. Commands in `src/commands/` glue them, mirroring perch's layout.

**Tech Stack:** Rust 2024; clap (derive), serde, serde_json, toml, toml_edit, reqwest (blocking, json), anyhow, dirs, jiff; dev: assert_cmd, predicates, tempfile.

**Spec:** `docs/design.md`

## Global Constraints

- Never touch the dotfiles repo or any path outside `~/.local/share/tally/`, `~/.cache/tally/`, the config file, and account folders' `.credentials.json` / `.claude.json`. Only exception: Task 12, which edits the dotfiles and needs the user's explicit go-ahead.
- No secrets in the config. Tokens are never printed or logged.
- Defaults: `five_hour = 0.18`, `min_session = 3`, `shared = ["CLAUDE.md", "settings.json", "keybindings.json", "skills", "agents", "commands", "plugins", "projects", "plans", "history.jsonl", "file-history"]`.
- Paths derive from `$HOME`: config `~/.config/tally/config.toml` (override `--config`), cache `~/.cache/tally/`, data `~/.local/share/tally/`, main dir `~/.claude`.
- Usage endpoint `GET https://api.anthropic.com/api/oauth/usage`, headers `Authorization: Bearer <token>`, `anthropic-beta: oauth-2025-04-20`. Refresh `POST https://platform.claude.com/v1/oauth/token`, JSON `{grant_type:"refresh_token", refresh_token, client_id:"9d1c250a-e61b-44d9-88ed-5944d1962f5e"}`. Timeout 3 s.
- Cache max age: `notice` 5 min, `pick`/`run` 1 min, `statusline` cache only + background refresh when older than 1 min, summary (`tally`) 1 min.
- Account names match `^[a-z0-9][a-z0-9-]*$`.
- The claude binary is `$TALLY_CLAUDE` if set, else `claude` on PATH.
- User-facing messages are lowercase, terse, perch's voice ("i couldn't …").
- Dependency versions as perch's `Cargo.toml` where shared; release profile copied from perch.

## Review Focus

- A `.credentials.json` with no `claudeAiOauth` (only `mcpOAuth`, e.g. after logout) must read as "not logged in", not an error. Test in Task 4.
- Cached usage whose `resets_at` has passed (laptop asleep over a reset) must count as 0% used. Test in Task 2.
- `dir = "~/.claude/"`, `"/home/<user>/.claude"` or `"$HOME/.claude"`-equivalent spellings must all be the main account (no `CLAUDE_CONFIG_DIR`, no links). Test in Task 1.
- Shell startup offline: `tally notice` must never error or block past the 3 s timeout; it prints from stale cache or nothing. Test in Task 6 (gather with failing `Net` + existing cache) and Task 10 (notice with no data).
- `tally add` on a machine with no config yet must keep the implicit main account in the file it creates. Test in Task 8.

### Task 6: Gathering usage (cache, refresh, parallel)

**Files:**
- Create: `src/usage.rs`

**Interfaces:**
- Consumes: `config::Account`, `credentials::{read, store_tokens}`, `api::{Usage, Tokens, ApiError, fetch_usage, refresh}`
- Produces:
  - `pub trait Net: Sync { fn usage(&self, token: &str) -> Result<Usage, ApiError>; fn refresh(&self, refresh_token: &str) -> Result<Tokens, ApiError>; }` and `pub struct Http;` implementing it with the api functions
  - `pub enum Status { Ready { usage: Usage, fetched_at: Timestamp, stale: bool }, NotLoggedIn, LoginExpired, Unavailable }`
  - `pub fn cached(account: &Account, cache_dir: &Path) -> Option<(Usage, Timestamp)>`
  - `pub fn status(account: &Account, cache_dir: &Path, max_age: SignedDuration, at: Timestamp, net: &dyn Net) -> Status`
  - `pub fn gather(accounts: &[Account], cache_dir: &Path, max_age: SignedDuration, net: &dyn Net) -> Vec<Status>` (same order; `std::thread::scope`, one thread per account)

Cache file: `<cache>/<name>.json` = `{"fetched_at": …, "usage": …}`.

`status` flow: fresh cache → `Ready{stale:false}`. No login → `NotLoggedIn`. Token expired (`expires_at ≤ at`) → refresh; on `Unauthorized`, re-read the file once and use it if now unexpired, else `LoginExpired`. Store new tokens with `expires_at = at_ms + expires_in × 1000`. Fetch; success → write cache, `Ready`. `Unauthorized` → `LoginExpired`. Other error → cached value as `Ready{stale:true}`, else `Unavailable`.
